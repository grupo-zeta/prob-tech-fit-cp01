# Demonstrações e evidências

Esta pasta está reservada para capturas de tela, GIFs e vídeos das tecnologias e do trabalho realizado pela equipe.

Para cada nova evidência, registre no card ou no pull request:

- Problema ou tarefa demonstrada e integrante responsável.
- Data, ferramenta e ação executada.
- Resultado observado e limitações do que a captura comprova.

Exemplo de nome: `cp01-problema3-harness-2026-09-16.png`.

Uma captura do harness deve mostrar a ferramenta e uma ação real, como leitura de arquivos, execução de comandos ou envio de um commit. Imagens ilustrativas e resultados simulados devem ser identificados dessa forma. Revise a captura para remover credenciais antes de publicá-la.
