# Core Contract — Unslop (`theclaymethod/unslop` + `heydamir/unslop`)

1. **Preserve Meaning and Functionality:** Never remove a feature, input, ID, or user control when de-slopping. Every DOM ID and interactive capability must continue working.
2. **Cut Formulaic AI Tells:**
   - Replace em-dash clauses (`—`) with periods or commas.
   - Replace `ALL CAPS` section headers with clean sentence-case titles.
   - Remove decorative symbols (`✦`, `⚡`, `🔒`, `☕`, `▣`, `◷`, `♧`) from copy.
3. **Quiet Chrome over Neon Slop:**
   - Surfaces must be neutral graphite/slate (`#111315`, `#17191c`, `#262930` hairlines).
   - No purple-to-cyan gradients, no glowing borders, no pulsing logo animations.
4. **Authentic Brand Anchor:**
   - Keep `brand.svg` untouched and derive primary interactive accents from its warm amber/terracotta tones (`#e87d3e` / `#f09356`).
