# Regras de Agentes e IA do Grupo Zeta

Este diretório contém o contexto e as regras estritas para a atuação de Inteligências Artificiais e LLMs neste repositório.

## Regras Globais
1. Nunca realizar commits na main sem validação.
2. Toda feature nova exige um spec-kit aprovado na pasta docs/specs.
3. Documentar handoffs na transição de entregáveis.
