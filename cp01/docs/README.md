# Relatório e documentação

- [fundamentacao_problemas.tex](fundamentacao_problemas.tex): trecho LaTeX dos quatro problemas da CP-01. Não contém preâmbulo nem `\begin{document}`; não é um documento independente para compilação.
- [Projeto do Overleaf](https://www.overleaf.com/project/6a922427f1ca2007335f685f): projeto de edição do relatório, sujeito às permissões da equipe.

## Atualizar uma cópia ou exportação

1. Confira a versão atual no Overleaf e compare com os arquivos do GitHub.
2. Exporte o PDF compilado ou os fontes necessários, incluindo bibliografia e dependências quando aplicável.
3. Registre no pull request a data da exportação, a origem e as seções atualizadas.
4. Confira as citações e abra o PDF antes de disponibilizar a entrega.

Para novos PDFs, pode-se usar `cp01-relatorio-AAAA-MM-DD.pdf`. Os PDFs diretamente em `docs/` são permitidos pelo `.gitignore` atual.

A cópia LaTeX existente foi preservada nesta organização. Ela não deve ser considerada automaticamente sincronizada com o Overleaf; a revisão do Problema 3 enviada ao Overleaf em 16/09/2026, commit `523b2ff`, pertence ao histórico daquele repositório.
